# Support

This is a community-maintained open-source project with no support SLA.

## Where to get help

**Bugs in this MCP server** — open an issue using the bug report template: <https://github.com/daften/mealie-mcp/issues/new/choose>

**Feature requests** — open an issue using the feature request template: <https://github.com/daften/mealie-mcp/issues/new/choose>

**Questions about Mealie itself (not this MCP server)** — please use the upstream channels:

- Mealie discussions: <https://github.com/mealie-recipes/mealie/discussions>
- Mealie documentation: <https://docs.mealie.io/>

**Questions about the MCP protocol** — see the MCP specification discussions: <https://github.com/modelcontextprotocol/specification/discussions>

## Security issues

See [SECURITY.md](SECURITY.md) — do not file public issues for vulnerabilities.

## Response expectations

This is a side project. The maintainer responds when time allows; there is no guaranteed turnaround. Pull requests are welcome — see [CONTRIBUTING.md](CONTRIBUTING.md) for the development loop and conventions.
