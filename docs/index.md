# Mealie MCP

Connects AI assistants to [Mealie](https://mealie.io). Start with one of the guides:

- [stdio](/guide/stdio): one person, on their own machine.
- [Docker and API keys](/guide/docker): a shared server where each client sends its own key.
- [Login form](/guide/login-form): a shared server where people log in with their Mealie account.
